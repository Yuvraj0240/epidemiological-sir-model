# Mathematical Epidemiological Modeling (SIR)

A deterministic mathematical framework designed to numerically simulate and forecast infectious disease propagation dynamics across fixed population scales.

## Features
* **Numerical Integration:** Solves non-linear ordinary differential equations (ODEs) using SciPy's RK45 Runge-Kutta solver.
* **Forecast Calibration:** Automatically identifies peak concurrent infection thresholds and maps specific milestone day coordinates.
* **Analytical Annotation:** Generates publication-quality Matplotlib trend lines plotting Susceptible, Infected, and Recovered cohorts over time.

## Core Technologies
* Python
* SciPy (Integration layer)
* NumPy
* Matplotlib
